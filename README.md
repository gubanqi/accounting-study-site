# 会计自习室

用户教材为《初级会计学》第9版。更新时不要替换为第10版或其他教材。

## 内容与来源

- 第1章20题、第2章30题、第7章32题来自对话中提供的学习指导书题图。
- 第3章14题、第4章18题、第5章12题、第6章12题为依据用户课件自编，不能标作教材原题或往年真题。
- 第7章现有课件仅“上”，对账、结账、错账更正等题册补充须保留来源说明。
- 题号保持稳定，以保留浏览器内练习记录。新增章节在 `build_content.py` 添加条目，或在输出后维护 `dist/chapters.json`。
- 不得把作答、看解析、自评过程混成自动验证。题目数量、参考用时不能当作掌握程度或高分保证。

## 详细学习升级（2026-10-22）

7章共76个详细单元、229道独立练习。原138题保持题号、题面、选项和答案；新增91题使用UP开头的新ID。教学例题另有EX编号，不写入练习记录。

每章四入口：详细学习（默认）、考前速记、章节练习、课件与范围。原`#chapter/章号/knowledge`链接进入详细学习；具体考点可用`/knowledge/单元ID`定位。搜索只索引详细讲解和题面，不索引例题解答或练习解析。

`upgrade_content.py`定义讲解、条件与步骤、易混点、完整例题和关联题号。`source-pages.json`保存8份PDF共347页的目录；生成的`COVERAGE.md`和网页逐页表提供课件页—讲解—例题—独立练习的映射。封面、目标、目录和分隔页单列。第7章缺少下半课件，补讲不等于完整覆盖老师课程。

课件要求标签按原目标归类；未单列的标“课件涉及”，缺课件正文的标补讲。原课件疑点和原解析课程口径补充均显示说明，不追改历史成绩。

## 运行与更新

Python只用标准库：运行 `build_content.py` 生成基础题与详细学习升级数据，并复制已存在的课件。该命令也生成`COVERAGE.md`，可重复运行。部署目录为dist，不需要安装前端依赖或构建框架。

检查：`node check.cjs`，`node --check dist/app.js`，`node --check dist/learning.js`。`check.cjs`对原138题使用`baseline-questions.json`逐项核对；也检查每个单元的来源、关联题号、347页映射和代表性计算。

浏览器验证：先在8766端口启动本地预览，再运行`node browser-check.cjs`。覆盖四个入口、例题不计分、搜索定位、旧记录、解析隐藏、错题复测、收藏与导入导出，以及390像素手机宽度。截图存于忽略目录qa，不发布个人测试记录。

本地预览可使用 `python -m http.server 8765 --directory dist --bind 127.0.0.1`。

网站是私有Sites。项目身份记录在`.openai/hosting.json`；复用相同project_id，不能重复创建。
使用Sites技能的source helper推送源码、打包并发布。保留现有访问范围。

## 添加新章节

用户已明确选择通过原对话更新，不使用付费OpenAI API。用户发课件后，读取全部相关内容，生成知识点与代表题，验证解答并更新同一站点。网站的“添加新章节”生成请求文字，不谎称网站会自动上传或AI生成。

课件也可先放入本地KJ项目对应文件夹，再在原对话告知文件名。本地文件移动本身不会触发生成或发布。更新已有章时保留章ID与旧题ID，新增题分配未使用过的新ID；新增章同时维护来源页码目录、讲解、速记与题目对应。

练习记录使用localStorage，仅在当前浏览器保存；导出/导入提供用户主动备份，不宣称跨设备同步。主观题要求先提交过程再自评，且不计入自动正确数。

升级内容数据的version为2；记录存储键仍为`accounting-study-room-records-v1`，导出文件version仍为1。导入保留首次记录、收藏、历史与每次自评计数标记，不清空其他题。部署文件不包含用户实际浏览器记录。

## 错题与复测

客观题答错或主观题自评仍需订正，自动设置needsReview并记录错题次数与时间。错题本始终不展示答案。闭卷再练会清空本次选项、文字、提交状态，并收起解析；首次作答和错题历史保留。
提前展开解析后做对不能清除待复测标记。未提前展开解析的复测答对，或主观题据已提交过程自评通过，才清除待复测标记；wrongCount与history仍保留。产品描述不能把“未展开本站解析”当作已验证用户真正闭卷或整章熟练。
