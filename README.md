# 会计自习室

用户教材为《初级会计学》第9版。更新时不要替换为第10版或其他教材。

## 内容与来源

- 第1章20题、第2章30题、第7章32题来自对话中提供的学习指导书题图。
- 第3章14题、第4章18题、第5章12题、第6章12题为依据用户课件自编，不能标作教材原题或往年真题。
- 第7章现有课件仅“上”，对账、结账、错账更正等题册补充须保留来源说明。
- 题号保持稳定，以保留浏览器内练习记录。新增章节在 `build_content.py` 添加条目，或在输出后维护 `dist/chapters.json`。
- 不得把作答、看解析、自评过程混成自动验证。题目数量、参考用时不能当作掌握程度或高分保证。

## 运行与更新

Python只用标准库：运行 `build_content.py` 生成数据并复制已存在的课件。部署目录为dist，不需要安装前端依赖或构建框架。

检查：`node check.cjs`，`node --check dist/app.js`。

本地预览可使用 `python -m http.server 8765 --directory dist --bind 127.0.0.1`。

网站是私有Sites。项目身份记录在`.openai/hosting.json`；复用相同project_id，不能重复创建。
使用Sites技能的source helper推送源码、打包并发布。保留现有访问范围。

## 添加新章节

用户已明确选择通过原对话更新，不使用付费OpenAI API。用户发课件后，读取全部相关内容，生成知识点与代表题，验证解答并更新同一站点。网站的“添加新章节”生成请求文字，不谎称网站会自动上传或AI生成。

练习记录使用localStorage，仅在当前浏览器保存；导出/导入提供用户主动备份，不宣称跨设备同步。主观题要求先提交过程再自评，且不计入自动独立正确数。
